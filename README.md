# Python Core Logic & Practical Utilities Portfolio

A comprehensive collection of Python scripts demonstrating fundamental programming concepts, graphical user interfaces (GUI), core data processing pipelines, and computational utility applications. 

## 📁 Repository Scripts Overview

This workspace serves as a repository for practical, modular code applications:

### 🎨 Visual & UI Applications
* **`color_app1.py` / `color_app2.py` / `color_app3.py`** – Dynamic script modules handling graphical interface layout rendering, color-picking configurations, or display variations.
* **`digital.clock.py`** – A functional real-time desktop digital clock utility.
* **`greeting_app.py`** – An interactive user greeting interface handling basic inputs.

### 📊 Calculation & Computational Utilities
* **`interest_calci_app.py` / `intrest_calci_app.py`** – Mathematical tools engineered to calculate simple and compound financial interest returns.
* **`p1_sq_root_app.py`** – Core computational script designed to calculate exact square roots.

### 🔢 Core Logic & Control Flows
* **`even odd integer app.py`** – Clean implementation of basic conditional logic evaluating integer inputs.
* **`p2_tc_app.py`** – Dedicated processing routine managing targeted application control flows.
